About this edition

Marmont uses a proposed historical reading with some uncertain assignments. Templar uses the A–Z and 0–9 mappings from the supplied reference charts. Raw images remain untouched. Crisp creates temporary black-and-white copies with a grayscale cutoff of 190/255; faint strokes may disappear. Cipher definitions and the engine are stored in separate JavaScript files. Keep the folder together to run offline.
